# QL Meet V0.0.1

POC video meeting menggunakan Next.js + LiveKit.

## Environment variables
Set di hosting/local environment, jangan commit secret:
- LIVEKIT_URL
- LIVEKIT_API_KEY
- LIVEKIT_API_SECRET

## Test
1. Deploy aplikasi.
2. Buka dari laptop dan HP.
3. Masukkan nama berbeda tetapi Room yang sama.
4. Izinkan kamera dan mikrofon.
5. Uji audio, video, dan screen share.

Tahap berikutnya setelah POC berhasil: role host/participant dan YouTube RTMP egress.
